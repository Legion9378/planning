Diese Datei sammelt Ideen, die unterwegs schnell notiert wurden. Der Zweck ist Wiedervorlage: Eine Idee gilt erst als abgearbeitet, wenn sie entweder in ein Fachkonzept uebernommen, verworfen oder bewusst geparkt wurde.

## Regel

- Jede mobile Idee bekommt Thema, Zielbereich, Status und naechsten Schritt.
- Incoming-Archive sind keine Wiedervorlage. Relevante Ideen muessen hier oder in einem fachlich passenden Planning-Dokument sichtbar werden.
- Wenn eine Idee nicht sofort ausgearbeitet wird, bleibt mindestens ein kurzer naechster Schritt stehen.
